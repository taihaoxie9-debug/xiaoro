# Old-Question Decision v1

## Decision

Historical fixed fixtures, real captures, zero-API replays, the old Blind A/B,
and the old blind pool are seen material. They are not another qualification
set and will not be rerun as a new 100-turn exercise.

The only allowed use of old material is to identify a shared responsibility
defect:

```text
model parent translation
source admission
Canonical product/image binding
Router or state transition
data coverage
public presentation
```

No old sentence, product ID, or stale result set may become a production
special case.

## Reviewed Failure Classes

| Evidence | Classification | Decision |
|---|---|---|
| Exact exclusion/revision/pending wording parsers | `shared_architecture_defect` | Provider-backed action authority moved to typed parent atoms; legacy action parsers must remain non-authoritative and mechanically isolated. |
| `抗老先撤掉，改成保湿修护优先` | `shared_architecture_defect` | Closed by typed efficacy remove plus new preference atoms; no wording parser is accepted as the fix. |
| `对，五百就是上限` and negated old budget | `shared_architecture_defect` | Closed by typed pending `correct` and `reject` atoms; code applies them to stored pending state. |
| Active consultation plus standalone definition question | `shared_architecture_defect` | v23 real probe translated to `knowledge + new_task`, routed to general knowledge, and preserved consultation observations. |
| Legal `current_item` later rejected by fuzzy alias scanning | `shared_architecture_defect` | Closed by trusting an admitted source-grounded current item before uncontrolled ambiguity scanning. |
| New complete shopping request bound to the previous candidate batch | `shared_architecture_defect` | Closed by typed `new_task` release of the old batch. |
| Three visible products plus explicit request for two | `shared_architecture_defect` | Closed by typed `batch_size_hint`; mismatch now clarifies instead of silently binding all three. |
| Historical sunscreen fixture expected IDs `53/55` while current eligible cards are `56/58/53` | `stale_fixture` | Do not roll retrieval back to old IDs. Current products satisfy the category and budget facts. |
| Historical two-card assumptions after the product moved to three cards | `stale_fixture` | Do not train the model on an obsolete card count. Validate explicit batch size against current visible state. |
| Safe equivalent clarification wording | `ordinary_model_variation` | Do not repair when the typed route, state, and safety behavior are correct. |
| High-confidence wrong product/image, unauthorized state, or unsafe downgrade | `serious_binding_or_state_failure` | Zero tolerance in the new blind exam and browser run; abort only the active paid command, preserve evidence, and repair the earliest shared layer. |
