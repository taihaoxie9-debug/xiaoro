## 这是什么

这是以远程可跑 demo(`github.com/TaiHaoXie/xiaoro` main)为**干净地板**、
在其上规划的六层重建骨架。目的：把旧仓库里"好料 + 施工架 + 垃圾"糊在一起的状态，
收敛成一个清爽起点。

## 为什么要这么做（一句话）

旧仓库不是失败，是"施工现场没收拾"：
- **真资产**（103商品审核 + typed合同 + 稳定排序 + 新前端）是干净的、值钱的、可直接搬。
- **负债**（agent.py 4957行 / presenter.py 6633行 / 三套意图层）是形态搭歪了，要重写。
- **垃圾**（空文件 / freeze脚手架）直接扔。

远程 demo 只有 12 个 v2 文件、没有审核数据——它是"起点"，不是"家"。
真正的成果只在旧仓库本地。所以：**以远程为地板，把本地真资产搬进来。**

## 已确认的关键决策（用户拍板）

1. 三期是终态，但**先做地基**，三期能力(视频/达人/实时学习)留可插拔接口。
2. 意图层分工：**槽位=代码字段，意图分类=大模型，向量只用于商品召回**，砍伪语义层。
3. 大模型可开，但**只输出意图分类，绝不碰商品事实**。
4. 重建起点：**远程副本做地板，先立骨架和清单，再从旧仓库搬真资产。**
