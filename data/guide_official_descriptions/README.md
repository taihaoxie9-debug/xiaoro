# Official Description Candidates

This directory stores exact excerpts and reviewed candidates from public brand websites.

- It is not loaded by the runtime.
- `official_description` rows are display-only under the current source policy.
- Official product-label rows remain `pending_manual_promotion`.
- No row has hard-filter capability.
- Product identity, source URL, local source SHA-256, exact source text, and proposed field are preserved.
